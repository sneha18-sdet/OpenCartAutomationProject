# OpenCart Automation Framework 

##  Project Overview

This project automates an OpenCart-based e-commerce web application using **Java, Selenium WebDriver, TestNG, and Cucumber (BDD)**.

A robust **hybrid automation framework** is designed using the **Page Object Model (POM)** to ensure scalability, maintainability, and reusability.

---

##  Tech Stack

* Java
* Selenium WebDriver
* TestNG
* Cucumber (BDD)
* Maven
* Extent Reports

---

##  Key Features

* User Registration
* Login (Valid & Invalid Scenarios)
* Product Search
* Add to Cart
* Checkout Process
* Forgot Password
* Order History Validation

---

##  Framework Highlights

* Hybrid framework using **POM + BDD (Cucumber)**
* Implemented **Explicit Waits** for dynamic elements
* **Reusable utilities** for common actions
* **Data-driven testing** using external data sources
* **Screenshot capture on failure**
* Integrated **Extent Reports** for detailed reporting

---

##  Project Structure

src/
├── test/java (Test Cases & Step Definitions)
├── main/java (Page Objects & Utilities)
├── features (Cucumber feature files)
├── runners (TestNG/Cucumber runners)
├── reports (Extent Reports)


---

##  Reporting

* Extent Reports are generated after execution
* Includes screenshots for failed test cases
